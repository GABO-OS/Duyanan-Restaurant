7. RISKS IDENTIFIED
================================================================================

  1. Uncaught Front-End Exceptions on Non-JSON Errors
     - Impact: High. Non-JSON payloads crash the frontend, breaking UI feedback.
     - Recommendation: Validate response content-type headers before parsing.

  2. Missing Dropdown Error States
     - Impact: Medium. Failed status updates leave dropdowns in incorrect
               states because the UI doesn't catch the failed response.
     - Recommendation: Revert dropdowns on failures and display error modals.

================================================================================
8. RECOMMENDATIONS
================================================================================

  1. Ensure Spring Boot backend controllers return standard JSON objects for all
     error states rather than empty/plain-text responses.
  2. Implement safe JSON parsing blocks in the frontend fetch requests.
  3. Add status dropdown rollback logic on API failures.
  4. Write automated integration tests (Cypress/Playwright) to verify validation
     rules on status updates and cancellations.
